frontend localhost:3000

This page is served by the example itself, on localhost:3000, and reached through a tunnel. Nothing else needs to be running.

Its heading is position: sticky, which pins on the vertical axis only — scroll this tile sideways and the heading travels with the content. That is ordinary CSS, and it looks the same in a tunnel tile as it does in a tab of its own.
